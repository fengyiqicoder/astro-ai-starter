# Changelog

Dependencies are updated on the first of every month; each update gets an entry here.

## 0.1.0 (unreleased)

First release.

- Blog on Astro 7, Tailwind CSS 4, MDX, Pagefind, RSS, sitemap, llms.txt, light and dark mode.
- Reader-side AI, all from the browser through OneTag AI with a public key: Ask the blog, TL;DR, Translate in place, Plain English, Ask the author, Read next, Explain selection, Explain this code, Share draft, Test yourself, Reader fit.
- Build-time helpers: `npm run ai:meta` (description, tags, takeaways) and `npm run ai:alt` (image alt text), cached by content hash.
- Two more complete sites in `examples/`: docs (Starlight with Ask AI) and landing page (fit check and ask-the-page FAQ).
- One design kit across all three, with a dark mode.
- GitHub Pages workflow that deploys the blog and both examples.
