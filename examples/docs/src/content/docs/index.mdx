## What you get

<CardGrid stagger>
	<Card title="Ask AI, from your docs only" icon="star">
		Readers ask a question; the answer is written from the pages that match, with links to them. Nothing is made up from outside the site.
	</Card>
	<Card title="No backend, no API keys in code" icon="rocket">
		The site stays static. One public OneTag AI key goes in an environment variable; every account gets 1,000,000 free tokens a month.
	</Card>
	<Card title="Fast by default" icon="approve-check">
		Starlight's own search index does the retrieval. The AI script loads only when someone opens the dialog, so Lighthouse stays at 100.
	</Card>
	<Card title="llms.txt included" icon="document">
		The build writes an llms.txt so AI coding tools and search engines can read the docs too.
	</Card>
</CardGrid>
